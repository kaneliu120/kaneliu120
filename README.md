# Hi, I'm Kane 👋

> Building [**opendata.best**](https://opendata.best) — a self-serve public data API catalog covering **990+ government datasets across 42 countries**.

## What is opendata.best

Compliance teams, procurement buyers, and B2B sales platforms need fast, normalized access to sanctions lists, company registries, regulatory permits, building licenses, procurement notices, healthcare registrations, and more.

Most of this data is technically "public" but practically locked behind brittle government portals, inconsistent schemas, and rate-limited endpoints. I'm building a single REST API with **150+ prebuilt adapters against official sources** (never scraped) — so you can ship supplier screening, company verification, and bid monitoring without writing your own scrapers.
